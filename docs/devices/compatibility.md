## 各品牌 ADB 授权

桌面接管是**一次性授权**：在设备开启调试后，点「设置 → 桌面应用 → 一键设置桌面」，按屏幕提示确认，授权会写入 `WRITE_SECURE_SETTINGS`、使用情况、通知使用权等，之后无需电脑或脚本。

| 品牌 | 开启方法 |
| --- | --- |
| 小米 / Redmi | 设置 → 关于 → 连按「产品型号」进开发者模式，再开「ADB 调试」 |
| TCL / 雷鸟 | 设置 → 关于 → 本机信息，快速按「上下左右」，在「更多」里开 ADB |
| 其他 Android TV | 设置 → 设备偏好设置 → 关于 → 连按「内部版本号」7 次，开发者选项里开 USB 调试 |

小米待机后可能关闭 ADB，授权需在 ADB 可用时完成。

## 桌面入口与 ADB 保持（1.6 起）

- One 的「桌面」入口默认关闭，点「一键设置桌面」授权时才启用，所以刚装好时不会出现在系统的默认桌面选择里。
- 「设置 → 桌面应用 → 保持 ADB 调试开启」（默认关闭）：授权后，ADB 被固件（如小米待机后）关掉时，One 会自己再打开。开启后同一网络的设备都能连接 ADB，请仅在可信网络使用。
- 「还原原桌面」会同时把 TCL/雷鸟的开机启动项改回原值；若此时 ADB 不可用会提示，请连上后再点一次，卸载前务必先还原。
