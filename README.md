# OneTV

One 是面向 Android TV、投影仪和手机横屏的局域网工具，包含网页浏览、手机遥控、文件传输和常用应用桌面。

本仓库用于版本说明和安装包发布。

## 下载与安装

前往 **[最新版本](https://github.com/MrJelly/OneTV/releases/latest)** 下载 APK，或查看[全部版本](https://github.com/MrJelly/OneTV/releases)。

1. 将 APK 传到电视或投影仪，通过设备上的安装器安装。
2. 打开应用，按屏幕提示扫码配对手机。
3. 手机与电视连接同一局域网，即可使用遥控、文字输入和文件传输。

更新安装需要保持签名一致；请使用 Releases 中发布的正式安装包。SHA-256 校验信息随版本提供。

## 功能

- 直播播放、自定义节目单与统一收藏。
- 网页浏览、光标操作、缩放和网页收藏。
- 手机扫码配对，按键／滑动遥控、发送文字和上传文件。
- 图片和视频预览、调用系统 APK 安装器。
- 常用应用、全部应用及可选桌面入口。

## 兼容说明

应用最低支持 Android 4.4（API 19）。现代网站及网页视频的播放能力受设备固件、浏览器内核和硬件兼容性影响；Android 4.4 上的直播功能仍在验证，不能保证所有旧盒子可用。

跨应用遥控需要设备支持并由用户授权。默认桌面和开机启动受设备固件限制，应用不会禁用原厂桌面。第三方直播和网站内容不属于本项目，会员、DRM 和地区限制仍由网站决定。
